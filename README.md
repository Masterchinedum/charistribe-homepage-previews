# Charis Tribe homepage previews

Three standalone homepage designs published on GitHub Pages.

- [Design 1](https://masterchinedum.github.io/charistribe-homepage-previews/design-1/)
- [Design 2](https://masterchinedum.github.io/charistribe-homepage-previews/design-2/)
- [Design 3](https://masterchinedum.github.io/charistribe-homepage-previews/design-3/)

GitHub Pages publishes the root of the `main` branch. Each design includes its local assets; no build is required. Design 2's application navigation points to the existing church website at https://charistribe.vercel.app. Its forms retain their original demo behavior.
