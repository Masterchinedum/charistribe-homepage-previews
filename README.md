# Charis Tribe homepage previews

Three standalone homepage designs published on GitHub Pages.

- [Codex homepage](https://masterchinedum.github.io/charistribe-homepage-previews/codex-homepage/)
- [Claude redesign](https://masterchinedum.github.io/charistribe-homepage-previews/redesign-claude/)
- [Codex homepage v2](https://masterchinedum.github.io/charistribe-homepage-previews/codex-homepage-v2/)

GitHub Pages publishes the root of the `main` branch. Each design includes its local assets; no build is required. The Claude design's application navigation points to the existing church website at https://charistribe.vercel.app. Its forms retain their original demo behavior.
